🚀 PRÓXIMOS PASOS - CÓMO USAR
═══════════════════════════════════════════════════════════════════════════════════

1️⃣  PREPARACIÓN
    Windows:
    PS C:\Nova-Commerce> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
    
    Linux/Mac:
    $ chmod +x docker-manage.sh

2️⃣  CONFIGURACIÓN (Opcional)
    cp .env.example .env
    # Editar .env con valores seguros para producción

3️⃣  CONSTRUCCIÓN
    Opción A (Script interactivo):
    PS> .\docker-manage.ps1  # Seleccionar "1"
    
    Opción B (Comando directo):
    $ docker-compose build

4️⃣  DESPLIEGUE
    Opción A (Script interactivo):
    PS> .\docker-manage.ps1  # Seleccionar "3"
    
    Opción B (Comando directo):
    $ docker-compose up -d

5️⃣  VERIFICACIÓN
    $ docker-compose ps
    $ curl http://localhost:8080/actuator/health
